# SkillBridgeAI

An AI-powered platform to help students bridge skill gaps for job readiness by analyzing resumes and providing personalized recommendations.

## Features
- Resume upload and analysis
- Skill gap detection
- Personalized skill recommendations
- Admin dashboard for tracking students
- Student login and profile management

## Tech Stack
- Python, Flask
- SQLite
- HTML, CSS, JavaScript

## How to Run
1. Clone the repository
   ```
   git clone https://github.com/nithyashree200506-png/SkillBridgeAI.git
   ```
2. Install dependencies
   ```
   pip install -r requirements.txt
   ```
3. Run the app
   ```
   python app.py
   ```
4. Open in browser at http://localhost:5000
